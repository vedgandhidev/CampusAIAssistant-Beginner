# Integration with Matthew's original repo

This beginner track preserves the same technical architecture while simplifying the learning experience. It does not overwrite Matthew's advanced notebooks.

Copy the `student_track/` folder into the existing repository, along with `TEACHER_GUIDE.md`, `COLAB_TEACHER_SETUP.md`, and `requirements.txt` (or merge dependencies with the original file). Keep the original Phase 1/2/3 and Appendix A files unchanged.

The third beginner notebook includes real Ollama generation and FAISS; its live-chatbot functionality requires instructor setup and a model installed in the notebook's runtime.

Source project: https://github.com/mattjunior039/CampusAIAssistantTutorial
